## Analogapp Kurulumu

Bu depo icinde basit bir Django projesi bulunur. Calistirmak icin once [Python](https://www.python.org/) ve Django'yu kurmalisiniz.

```bash
pip install django
```

Ardindan proje klasorune girip veritabani migrasyonlarini olusturun ve gelistirme sunucusunu baslatin:

```bash
cd analogapp
python manage.py migrate
python manage.py runserver
```

Tarayicinizdan `http://localhost:8000` adresine giderek uygulamayi gorebilirsiniz.
